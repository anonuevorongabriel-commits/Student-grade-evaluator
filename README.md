Student Grade Evaluator App

Description
The Student Grade Evaluator App is a standalone Python application designed to evaluate the academic performance of a single student. The system computes the General Weighted Average (GWA), compares it with a target GWA, and displays a structured academic evaluation result.

Features
- Compute General Weighted Average (GWA)
- Set a target GWA
- Compare actual GWA with target GWA
- Display pass or fail status
- Display subject grades

Technologies Used
- Python 3
- Tkinter GUI
- Object-Oriented Programming (OOP)

OOP Principles Applied
- Encapsulation
- Polymorphism
- Loose Coupling

How to Run
1. Open the project folder
2. Run `main.py` or the GUI file
3. Input subject grades and target GWA
4. View the academic evaluation result
